## Review Findings

### 1. CRITICAL: `TvChannels.clearAll()` deletes ALL system Watch Next entries
**File:** `app/src/main/java/com/sinema/util/TvChannels.kt:105-114`

`clearAll()` queries `TvContractCompat.WatchNextPrograms.CONTENT_URI` and deletes **every** entry without filtering by `COLUMN_INTERNAL_PROVIDER_ID` or any app-specific identifier. This destroys other apps' watch-next data system-wide.

Fix: Filter deletions to only rows where `internal_provider_id` matches Sinema scene IDs, mirroring the logic in `syncWatchNext()`.

---

### 2. `TvChannels.syncWatchNext()` deletes other apps' Watch Next entries
**File:** `app/src/main/java/com/sinema/util/TvChannels.kt:33-41`

The deletion loop checks `!internalId.isNullOrBlank()` — any app that sets an internal provider ID will have its entries deleted by Sinema on every sync. Other apps (e.g., Netflix, Plex) may use this column.

Fix: Delete only entries whose `internal_provider_id` is a known Sinema scene ID, or prefix Sinema IDs and filter on that prefix.

---

### 3. SECURITY: API key leaked in artwork URIs passed to system launcher
**File:** `app/src/main/java/com/sinema/util/TvChannels.kt:166-173`

`artworkUri()` embeds the raw API key as a query parameter:  
`…/screenshot?apikey=${app.prefs.apiKey}`

This URI is passed to `setPosterArtUri()`, which the Android TV launcher processes. The launcher may cache, log, or persist this URI, exposing the key.

Fix: Use a content provider or download/cache thumbnails locally, then pass a `content://` URI. Alternatively, skip artwork for session mode and rely on launcher-side caching without credentials.

---

### Minor notes
- `PlaybackActivity.playDurationMs` calculation (`System.currentTimeMillis() - startTimeMs`) includes background/paused time because `startTimeMs` is only set in `onStart()` and never adjusted on resume. Inflated durations are sent to the server.
- `findScenesInternal` NPE risk: `data.get("count").asInt` throws if `count` is absent (pre-existing, now centralized).
- `SceneDetailActivity.loadRelatedScenes()` swallows all exceptions silently (`catch (_: Exception) {}`).
