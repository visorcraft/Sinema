# Credits and Acknowledgements

Sinema is maintained by VisorCraft LLC and depends on the work of several open-source projects.

## Core Projects

- [Stash](https://github.com/stashapp/stash): self-hosted media organizer and GraphQL backend that Sinema connects to.
- [Android Open Source Project](https://source.android.com/): Android platform APIs and Android TV platform behavior.
- [AndroidX](https://developer.android.com/jetpack/androidx): Leanback UI, Core KTX, Lifecycle, Security Crypto, TVProvider, and transitive Android support libraries.
- [Media3](https://developer.android.com/media/media3): ExoPlayer playback, HLS, player UI, and Leanback playback UI integration.
- [Glide](https://github.com/bumptech/glide): authenticated image loading and caching.
- [OkHttp](https://square.github.io/okhttp/): HTTP client for Stash GraphQL and setup/login requests.
- [Gson](https://github.com/google/gson): JSON parsing for GraphQL responses and stored profile data.
- [Kotlin and kotlinx.coroutines](https://kotlinlang.org/): Kotlin language/runtime and coroutine support.
- [Gradle](https://gradle.org/) and the [Android Gradle Plugin](https://developer.android.com/build): Android build tooling.
- [JUnit](https://junit.org/junit4/) and [Hamcrest](http://hamcrest.org/): unit test framework and assertions.
